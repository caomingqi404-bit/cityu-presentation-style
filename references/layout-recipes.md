# Layout recipes

Read only the recipes needed for the current material. Coordinates use the
1280 × 720 reference canvas. The four starter slides illustrate these recipes.

## Cover

Use the shared logo, rule and wave. Place the title around x=108, y=205 with up
to three short lines. Put the report type or subtitle below it, followed by a
presenter/affiliation field when supplied. Keep enough whitespace to make the
research subject the focal point. Do not invent a name or date.

## Main figure with side explanation

Use roughly two-thirds of the content width for the actual process, architecture
or result. The remaining side explains the question or implication. The starter
uses a neutral input/method/output diagram to show editable object placement.
Replace it with the subject's actual dataflow rather than repeating those three
labels in every talk.

## Controlled comparison

Use an editable table for baseline and candidate data. Place the conditions or
metric definitions near the table, and the supported finding underneath. Add a
native chart only when it makes the comparison clearer. Populate values from
the supplied evidence, preserving units, denominators and version boundaries.
The starter's empty-style text cells are layout examples, not research values.

## Future work with hierarchy

Give the immediate unresolved task the dominant left area, with a short
completion criterion. Place smaller follow-on items on the right and label their
dependencies. The example contains one main task plus three later tasks. Change
that count to match the user's plan; the point is hierarchy, not a fixed pattern.

Suggested regions:

- Main task: x=78–670, y=155–590.
- Follow-ons: x=735–1198, y=160–625.
- Optional final research question: x=103–1150, y=625–663.

Keep the rightmost text clear of the decorative wave. For long plans, shorten
or split the content instead of reducing the page to tiny labels.
