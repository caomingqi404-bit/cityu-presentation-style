# CityUHK presentation style

## Design authority

Use the bundled editable deck and preview as a visual reference. They contain
neutral example text. Reuse their design without treating that text as the user's
research, affiliation or results. This is a reusable personal style, not an
official university template or endorsement.

## Palette

| Role | Color |
| --- | --- |
| Background | `#FFFFFF` |
| Primary magenta | `#C0055A` |
| Secondary pink | `#E94E8D` |
| Pale curve / separator | `#F2D6E3` |
| Main text | `#202020` |
| Secondary text | `#5A6B7E` |
| Light border | `#E2E2E2` |

Use magenta to identify structure or a key result. Avoid coloring every label or
using decorative gradients as a substitute for a meaningful figure.

## Canvas and shared geometry

The reference uses a 1280 × 720 design canvas, equivalent to a 16:9 slide of
13.333 × 7.5 inches. Coordinates below are CSS pixels at 96 dpi. PowerPoint's
font and geometry units may differ: 24 CSS px = 18 pt.

| Element | x | y | width | height |
| --- | ---: | ---: | ---: | ---: |
| Small page marker | 54 | 29 | 45 | 42 |
| Slide title | 110 | 24 | 915 | 56 |
| Logo frame | 1050 | 8 | 148 | 80 |
| Header rule | 54 | 96 | 1172 | 2 |
| Main content area | 78 | 136 | 1120 | 510 |
| Decorative wave | 1120 | 558 | 160 | 110 |
| Optional footer | 54 | 675 | 800 | 20 |
| Footer page number | 1180 | 675 | 46 | 20 |

These are starting positions, not permission to squeeze long titles into the
logo area. Shorten, wrap or resize a title within its available region. Preserve
the logo's aspect ratio and keep the rule below its bilingual lettering.

## Typography

| Use | CSS px | Approx. pt |
| --- | ---: | ---: |
| Cover title | 48–56 | 36–42 |
| Slide title | 36–40 | 27–30 |
| Major section / result | 26–32 | 19.5–24 |
| Body / table | 22–26 | 16.5–19.5 |
| Caption | 17–20 | 12.75–15 |
| Footer | 13–15 | 9.75–11.25 |

The reference uses Microsoft YaHei. Use a locally available alternative when
needed, such as PingFang SC or Noto Sans CJK SC for Chinese. This is a fallback
choice to verify on the recipient's machine, not a promise of identical metrics.
No font files are included.

Prefer shortening copy and improving composition before shrinking body text.
Keep chart labels and code readable at the final projection size.

## Logo and wave

`assets/cityu-logo.png` is the retained raster logo from the original personal
style skill. Keep it unchanged in proportion and colors. The SVG wave and PNG
equivalent are decorative assets. Native matching curves are also acceptable.

Do not enlarge the wave into a full-slide background. Keep it within the lower
right region and away from notes, chart axes or result labels.

## Composition and evidence

Vary layouts to match the content: a dominant figure with side explanation, an
editable comparison table, a process diagram or a visibly ordered future-work
page. Repeated equal cards are suitable only when the underlying items warrant
equal treatment.

Research slides should help the audience identify the question, comparison
conditions, observation and boundary of the claim. Keep genuine screenshots as
images, with editable annotations around them. Keep tables and core diagrams as
native slide objects. Put detailed provenance in speaker notes when helpful.

## Visual check

Check every slide for title/logo clearance, intact logo proportions, readable
text, consistent margins and page markers, editable evidence objects, correct
language and sufficient separation from the wave. Do not treat a package or XML
check as proof of visual quality.
